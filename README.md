# DSA-PROJECT
This is DSA Project (Rutgers- DSA-512)
In this project Our task is to Transform the graph from Independent Set to Dominating Set.
Both are NP-complete problems. So if in a graph there exists a Independent Set with budget b, we must have Dominating Set with that budget & viceversa.

Input -
A graph - Present in input.csv
Budget b

Output -
Whether IS exists in the given graph by checking if DS is present.
